🛍️ Shopee – E-Commerce Website

🌟 About the Project
Shopee – E-Commerce Website is a frontend web development project designed to provide users with a simple, attractive, and convenient online shopping experience.
Users can explore different product categories, view products with prices, add products to their shopping cart, and access login and registration pages.
The website is designed with an attractive interface using HTML, CSS, and JavaScript.

✨ Key Features
- 🏠 Home Page: Attractive homepage with navigation and product sections.
- 🛒 Shopping Cart: Add products to the cart and manage selected items.
- 👗 Product Categories: Browse Electronics, Groceries, Clothing, and Furniture.
- 🖼️ Product Display: View product images, names, and prices.
- 🔐 User Login: Login page for existing users.
- 📝 User Registration: Registration form for new users.
- 🎨 User Interface: Attractive design with styling and interactive elements.

🚀 How to Run the Project
1. Clone this repository:
   
   git clone https://github.com/Aishu6289/Shopee-Ecommerce-Website.git

2. Open the project folder in Visual Studio Code.

3. Open the project files.

4. Run "index.html" using the Live Server extension.

5. Explore the Shopee E-Commerce Website in your browser.
